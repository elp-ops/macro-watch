# Macro Watch — Project Rules

See `brief.md` for scope and ground rules, `wiki/CLAUDE.md` for how the wiki is filed.

## Version Control

This repo (`elp-ops/macro-watch`) should not get a commit/push for every small edit. Push at significant milestones only:

- A structural change (new folder, new category, schema change to the wiki)
- A source/podcast fully processed into the wiki for the first time
- The thesis in `wiki/overview.md` materially shifts (not a typo fix)
- A new scout or pipeline component goes live

Not significant enough to push on their own: a single raw file drop, a minor wording edit, a `log.md` one-liner with nothing else changed. Let those accumulate locally and go out with the next real milestone.

**Standing authorisation:** commit and push at these milestones without asking each time. Flag it in the response either way so Elena can see what went out.
